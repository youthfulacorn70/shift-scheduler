# Shift Scheduler

A full-stack shift scheduling app for businesses that run on hourly shifts.

## Tech Stack
- Frontend: React + TypeScript + Tailwind CSS
- Backend: FastAPI (Python)
- Database: PostgreSQL
- Auth: JWT tokens + bcrypt

## Features
- Manager and employee login with separate views
- Create and manage shifts with a date picker
- Auto-schedule algorithm that prioritizes higher-rated employees
- Two-week calendar view for schedule display
- Role-based shift assignment
